# My Todo App

A simple todo app built with plain HTML, CSS, and JavaScript. No frameworks, no installs — just open and go!

## Features
- Add todos by typing and pressing Enter or clicking Add
- Click a todo (or the circle) to mark it complete
- Click ✕ to delete a todo
- Your todos are saved automatically — they'll still be there after you refresh

## How to Open Locally
1. Download or clone this repository
2. Double-click `index.html` to open it in your browser
3. Start adding todos!

## How It Works

The app is made of three files:

| File | What it does |
|---|---|
| `index.html` | Defines the structure of the page (the input box, list, etc.) |
| `style.css` | Makes everything look nice (colors, fonts, layout) |
| `script.js` | Handles all the behavior (adding, completing, deleting, saving) |

Todos are saved in your browser's `localStorage`, which means they persist even after you close the tab — no server or database needed!
